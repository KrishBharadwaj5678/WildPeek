<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/icons/icon.png" width="35"/> Wild Peek</h1>

<p align="center">
  Wild Peekは、動物の分類、生息地、行動、食性、身体的特徴など、さまざまな情報を詳しく提供する総合的な動物百科事典です。
</p>

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
|--------|-------------|
| 🔍 **動物検索** | あらゆる動物を検索し、詳細な情報にすぐにアクセスできます |
| 🐾 **詳細な情報** | 分類、生息地、外見、行動、食性、寿命など、さまざまな情報を確認できます |
| 📱 **レスポンシブインターフェース** | デスクトップ、タブレット、モバイルデバイスで快適に利用できます |

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/techStack.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/WildPeek.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd WildPeek
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
streamlit run app.py
```
