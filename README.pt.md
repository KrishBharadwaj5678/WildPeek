<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/icons/icon.png" width="35"/> Wild Peek</h1>

<p align="center">
  Wild Peek é uma enciclopédia completa de animais que fornece informações detalhadas sobre a classificação das espécies, habitat, comportamento, alimentação, características físicas e muito mais.
</p>

![WildPeekDemo](https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/demos/WildPeekDemo.png)

<img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
|--------|-------------|
| 🔍 **Pesquisa de Animais** | Pesquise qualquer animal e acesse informações detalhadas instantaneamente |
| 🐾 **Informações Completas** | Explore classificação, habitat, aparência, comportamento, alimentação, expectativa de vida e muito mais |
| 📱 **Interface Responsiva** | Tenha uma experiência perfeita em computadores, tablets e dispositivos móveis |

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/techStack.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/WildPeek.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd WildPeek
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar a Aplicação

```bash
streamlit run app.py
```
