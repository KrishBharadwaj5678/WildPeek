<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/icons/icon.png" width="35"/> Wild Peek</h1>

<p align="center">
  Wild Peek это подробная энциклопедия животных, содержащая информацию о классификации видов, среде обитания, поведении, рационе, физических характеристиках и многом другом.
</p>

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|--------|-------------|
| 🔍 **Поиск животных** | Найдите любое животное и мгновенно получите подробную информацию о нём |
| 🐾 **Подробная информация** | Изучайте классификацию, среду обитания, внешний вид, поведение, рацион, продолжительность жизни и многое другое |
| 📱 **Адаптивный интерфейс** | Пользуйтесь приложением с комфортом на компьютерах, планшетах и мобильных устройствах |

## <img src="https://github.com/KrishBharadwaj5678/WildPeek/raw/main/assets/readme/techStack.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/WildPeek.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd WildPeek
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
